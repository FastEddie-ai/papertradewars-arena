# PaperTradeWars Arena — DEPLOY_NOTES

Public-ready build, verified 2026-09-15. Ed deploys from his iPhone (Working Copy flow).

## What you're deploying
The PaperTradeWars website: Season 1 scoreboard (ChatGPT, Grok, Claude, Gemini,
Muse, Bananas the monkey + human drafters), live price feeds, admin price
controls, `/board-image` for video production. Week 1 is LIVE now (cutoff
Tue Sep 22, 2026 4:00 PM ET) with the real locked entry prices baked in.

## Before you start (have these ready)
1. A **new empty GitHub repo** (e.g. `papertradewars-arena`).
2. A **Turso database** (free tier is fine) — you need:
   - `TURSO_DATABASE_URL` (libsql://...)
   - `TURSO_AUTH_TOKEN`
   Ed keeps these in his Notes app. The app REQUIRES Turso in production —
   Render's free tier has no persistent disk, so the local SQLite fallback
   would wipe on every redeploy. The fallback is for local dev only.
3. The deploy zip: `papertradewars-arena-site.zip` (in your_files).

## Deploy steps (phone, ~30 min)
1. In the Files app: Share `papertradewars-arena-site.zip` → "Copy to Working
   Copy" → pick your new `papertradewars-arena` repo → Extract (overwrites
   in place) → commit → push with the sync button. (Same flow as the Arena fixes.)
2. Render dashboard → New → Web Service → connect the repo.
   - Build command: `npm install`
   - Start command: `node server.mjs`
   - Plan: Free. Health check path: `/api/health`
3. In the service's Environment tab, set:
   - `TURSO_DATABASE_URL` = your libsql URL
   - `TURSO_AUTH_TOKEN` = your token
   - `APP_URL` = the https Render URL of this service (enables Secure cookies)
   - `ADMIN_SECRET` is auto-generated by render.yaml — find its value in the
     dashboard after first deploy; that's your `/admin` password.
   - `SITE_TITLE` is pre-set to `PaperTradeWars` (leave it).
4. Deploy. Wait for "Live", then open `/api/health` — expect
   `{"ok":true,"site":"PaperTradeWars","db":"turso","week":1}`.
   (`"db":"turso"` is the important part — if it says `local-sqlite`,
   the Turso vars aren't set right.)

## Post-deploy checks (5 min)
- Open `/` — Week 1 board shows all six contestants with their five picks each.
- `/admin` (paste ADMIN_SECRET): "Fetch & update CURRENT prices" once, then
  check `/` shows live % returns.
- Register a test account, submit a draft, confirm it appears on the board.
- `/board-image` renders the scoreboard graphic (used for TikTok production).

## Notes
- Week 1 entry prices are pre-seeded (source "week1-lock") — do NOT re-snapshot
  entry prices; that would overwrite the real locked entries.
- New-week rollover and current-price refreshes happen in `/admin`.
- No broker links, no subscriptions, no Google login in this build (all parked).
- Google OAuth is the planned next auth upgrade, not yet built.
